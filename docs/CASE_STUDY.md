# Case Study — Gym Customer Churn Prediction

## Problem
Gym operators need early warning signals to reduce customer churn and protect recurring revenue.

## Solution
A machine learning pipeline that:
- preprocesses mixed numerical/categorical data,
- compares multiple models,
- serves churn probability through an API.

## Outcome
- reproducible training + model artifact flow,
- deploy-ready API endpoint,
- model card for transparent metric tracking.
